# Olive Events

> Luxury Event Management & Bespoke Experiences in India.

An interactive, high-end web experience showcasing weddings, destination celebrations, corporate galas, and bespoke events.

## Tech Stack

- **React 18** with **TypeScript**
- **Vite** for fast bundling and development
- **Tailwind CSS** for styling
- **Framer Motion** & **GSAP** for smooth animations
- **Three.js** for 3D interactions
- **Lenis** for smooth scrolling

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm / pnpm / yarn

### Installation

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

### Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
